Local server API

The server listens on loopback. Browser and CLI clients use JSON unless a route returns HTML or a static asset.

Health and lifecycle

GET /api/health

Returns name, version, and, for a managed server, instanceId and protocolVersion.

POST /api/shutdown

Returns 202 and schedules shutdown. A managed server requires its x-zatto-instance-id header; a mismatch returns 409.

Session

GET /api/session

Returns ordered entries plus server identity and native file/folder picker capabilities.

POST /api/session/add

Body: { "paths": ["page.html"] }. Paths are resolved to absolute paths; existing paths not already in the session are added once. The endpoint does not require an HTML file extension. The response is 201 with added and session.

POST /api/session/pick

Opens the managed native file picker. Requires x-zatto-instance-id. It returns 501 when unavailable and 409 while another native picker is active.

POST /api/session/pick-directory

Body: { "mode": "direct" } or { "mode": "recursive" }. The identity, availability, and single-picker rules match the file picker.

PATCH /api/session/order

Body: { "ids": [...] }. The list must contain every current entry ID exactly once. Success returns 204.

DELETE /api/session/:id

Removes one entry. Returns 404 for an unknown ID and 204 on success.

DELETE /api/session/entries

Body: { "ids": [...] }. IDs must be non-empty, unique, and known. The operation is atomic and returns 204.

DELETE /api/session

Clears all entries and returns 204.

Session exchange

GET /api/session/export

Returns { "format": "zatto-session", "version": 1, "entries": [{ "path": ... }] } in display order.

PUT /api/session

Validates a version 1 exchange document. ?mode=replace is the default; ?mode=merge appends unregistered paths. Managed servers require x-zatto-instance-id.

Search

GET /api/search

The q query parameter is a case-insensitive fixed string matched in HTML source. Empty text returns no matches. Queries are limited to 256 UTF-16 code units; file, match, and response limits may set truncated.

AI agent context

GET /api/agent/context

Returns schema version 1 with the selected file or null, every open file in display order, and the current preview, search, or docs view. Each file has an untrusted title for candidate selection and an authoritative absolute path. Title whitespace is normalized, Unicode control and format characters are removed, and output is limited to 200 Unicode code points. An empty result falls back to the file name. Outside the preview view, the active file remains the session selection and may not be visible. The endpoint never returns HTML contents.

PUT /api/agent/context

The browser reports { "activeEntryId": string | null, "view": ... }. This volatile state is not persisted or included in session exchange files.

Preview and realtime

GET /f/:id/Returns the selected entry's HTML.
GET /f/:id/*Returns a relative asset with its MIME type. Requests outside the entry directory are rejected.
WS /wsSends session:update after session changes and file:changed when a watched file changes.

Web resources

GET /Returns the built web application, or a service-unavailable page when it is absent.
GET /manifest.webmanifestReturns the web app manifest.
GET /assets/*Returns frontend build assets without allowing traversal outside the assets directory.
GET /docs/*Returns bundled documentation without allowing traversal outside the docs directory.
