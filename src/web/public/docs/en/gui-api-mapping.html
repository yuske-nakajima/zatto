Operations without a direct GUI control

session.add is used by the CLI to add path arguments. server.health identifies a compatible server, and server.shutdown supports the stop command.

Docs are built-in content. They do not become session entries and are excluded from List, Folders, HTML search, import, export, removal, and ordering.

Workspace controls

Workspace reads metadata from session.get and activates with workspaces.activate. New workspace uses workspaces.create then activates the returned ID. Rename uses workspaces.rename; confirmed deletion uses workspaces.delete. WebSocket updates synchronize selection, files, and order across tabs. Browser mutations carry the displayed workspace ID to reject stale operations.

Favorite controls

Each row's star sends an explicit boolean to session.setFavorite. The button exposes its state through aria-pressed and supports Enter and Space. Favorites filters session entries locally and writes fileView=favorites to browser history. Updates synchronize through session:update; the complete List order remains unchanged. In Favorites, drag handles are absent and Clear All is disabled.

CLI file arguments print titles and entry links after the top URL. Each link selects its registered entry through the browser URL; keep the registration workspace active. The add response resolves both existing and added files without changing List order.

JSON-RPC

All operation names in this table are methods sent to POST /rpc. Files and WebSocket events keep the HTTP/WS routes shown. The API page defines params, result and error. The logo shows the package version; Docs includes an offline Changelog.
