ローカルサーバーAPI

サーバーはループバックで待ち受けます。HTMLや静的アセット以外は、ブラウザーとCLIがJSONで通信します。

ヘルスチェックとライフサイクル

GET /api/health

nameとversionを返します。管理対象サーバーでは、instanceIdとprotocolVersionも返します。

POST /api/shutdown

202を返して停止を予約します。管理対象サーバーではx-zatto-instance-idが必須で、不一致は409です。

セッション

GET /api/session

表示順のエントリ、サーバー識別子、ネイティブのファイル・フォルダー選択機能を返します。

POST /api/session/add

本文は{ "paths": ["page.html"] }です。パスを絶対パスへ解決し、存在していてセッションに未登録のパスを1回だけ追加します。HTMLの拡張子は必須ではありません。201とadded、sessionを返します。

POST /api/session/pick

管理対象のネイティブファイル選択を開きます。x-zatto-instance-idが必要です。利用不可は501、別の選択画面が開いている場合は409です。

POST /api/session/pick-directory

本文は{ "mode": "direct" }または{ "mode": "recursive" }です。識別子、利用可否、同時に1つだけ開く規則はファイル選択と同じです。

PATCH /api/session/order

本文は{ "ids": [...] }です。全エントリIDを重複なく1回ずつ指定します。成功時は204です。

DELETE /api/session/:id

1件のエントリを削除します。不明なIDは404、成功時は204です。

DELETE /api/session/entries

本文は{ "ids": [...] }です。空でない既知のIDを重複なく指定します。処理は原子的で、成功時は204です。

DELETE /api/session

全エントリを削除し、204を返します。

セッション交換

GET /api/session/export

表示順で{ "format": "zatto-session", "version": 1, "entries": [{ "path": ... }] }を返します。

PUT /api/session

version 1の交換JSONを検証します。既定の?mode=replaceは全置換、?mode=mergeは未登録パスの追加です。管理対象サーバーではx-zatto-instance-idが必要です。

検索

GET /api/search

qの大文字・小文字を区別しない固定文字列をHTMLソースから検索します。空文字は結果なしです。クエリーはUTF-16で256コード単位までで、ファイル、件数、応答量の上限到達時はtruncatedを返します。

AIエージェント向けコンテキスト

GET /api/agent/context

schema version 1として、選択中の絶対パスまたはnull、表示順の全絶対パス、現在のpreview、search、docs表示を返します。HTML本文は返しません。

PUT /api/agent/context

ブラウザーが{ "activeEntryId": string | null, "view": ... }を通知します。この一時状態は永続化せず、セッション交換JSONにも含めません。

プレビューとリアルタイム更新

GET /f/:id/選択したエントリのHTMLを返します。
GET /f/:id/*MIME付きで相対アセットを返します。エントリの基点ディレクトリ外へのアクセスは拒否します。
WS /wsセッション変更時にsession:update、監視ファイル変更時にfile:changedを送ります。

Webリソース

GET /ビルド済みWebアプリを返します。存在しない場合はサービス利用不可ページを返します。
GET /manifest.webmanifestWebアプリマニフェストを返します。
GET /assets/*assetsディレクトリ外への移動を拒否し、フロントエンドアセットを返します。
GET /docs/*docsディレクトリ外への移動を拒否し、組み込みドキュメントを返します。
