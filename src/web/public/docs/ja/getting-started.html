はじめに

複数のローカルHTMLファイルを、1つのブラウザーセッションで閲覧します。

zattoを起動する

グローバルインストールせずに起動できます。ブラウザーが開き、コマンドの終了後もローカルサーバーは動作を続けます。

npx @yuske-nakajima/zatto

起動と同時に、1つ以上のファイルを追加することもできます。

npx @yuske-nakajima/zatto page.html report.html

ファイルを追加する

macOSでは、+ Add、Select HTML files、またはCommand+Oを使います。既存の.htmlファイルと.htmファイルを選択できます。

Add folder…では、選択フォルダー直下または子孫を含むHTMLファイルを追加できます。シンボリックリンクは無視し、登録済みパスは重複追加せず、相対パス順に追加します。

閲覧・検索する

  • ListまたはFoldersでファイルを選ぶと、プレビューを表示します。
  • ファイルパネルの区切りをドラッグすると幅を変更できます。ダブルクリックすると既定の幅へ戻ります。
  • Searchでは、セッション内の全HTMLソースから固定文字列を検索できます。
  • 開いているファイルの変更は、プレビューと検索結果へ反映されます。

エントリやフォルダー行を削除しても、zattoのセッションから外れるだけです。ディスク上のファイルやフォルダーは削除しません。

セッションを保存・復元する

Export session…は、開いているファイルパスと表示順を保存します。Import session…では、一覧の全置換または未登録パスの追加を選択できます。

セッションJSONには絶対パスが入り、ローカルのアカウント名やディレクトリ名が含まれる場合があります。利用するコンピューター内で保管してください。

サーバーを停止する

npx @yuske-nakajima/zatto --stop
