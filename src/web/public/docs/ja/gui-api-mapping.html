GUIとAPIの対照表

ブラウザーUIは同じローカルサーバーのクライアントです。画面操作の背後で使うリクエストを示します。

GUIの動作サーバー操作UIへの反映
ビューアーを開くsession.get表示順のエントリ、サーバー識別子、選択機能の利用可否を読み込みます。
ファイルを選択GET /f/:id/プレビューiframeへHTML、またはHTMLへ変換したMarkdownを読み込みます。相対リソースにはGET /f/:id/*を使います。
Docsページを開くGET /docs/*セッションエントリを作らず、選択した言語とページを同一オリジンのiframeへ読み込みます。
セッション・ファイル変更を受信WS /wsファイルパネル、プレビュー、検索状態を更新します。
コメントのスレッドを読み込むreview.list / review.states選択中ファイルのスレッド、レビュー中のファイル、未解決のスレッド数を読み込み、review:updateとreview:statesの通知に追従します。ファイル一覧にはスレッド数を表示し、レビュー中はIn reviewを付けます。
Comment / Reply / Edit / Deletereview.create / review.reply / review.edit / review.deleteスレッドを保存し、強調表示を更新します。
Resolve / Reopenreview.resolve解決したスレッドは強調表示しません。
Ask an LLM to review—LLMの会話に貼る依頼文をコピーします。貼られたLLMがzatto reviewを実行し、review.startを呼びます。
Finish reviewreview.finishレビューを終え、LLMのセッションが未解決のスレッドを受け取ります。
Markdownのタスクのチェックを切り替えmarkdown.setTaskチェックの状態をファイルへ書き込みます。ファイルが変更されていた場合は、最新の内容でプレビューを読み直します。
ファイルを検索search.queryソース内の固定文字列一致と打ち切り状態を表示します。
Select HTML or Markdown filessession.pickFilesネイティブファイル選択を開き、追加した最初のエントリを選択します。
Add folder…session.pickDirectory選択した直下・再帰範囲を使い、追加した最初のエントリを選択します。
ドラッグで並べ替えsession.reorder完全な表示順を永続化します。
ファイル行またはプレビューから1件削除session.removeディスク上のファイルを削除せず、選択中のエントリをセッションから外します。
フォルダー行を削除session.removeMany配下の全セッションエントリを原子的に削除します。
セッションを消去session.clear確認後、全セッションエントリを削除します。
Import session…session.import選択したモードに従い、全置換または未登録パスの追加を行います。
Export session…session.exportセッションを変更せず、表示順またはパス順のJSONをダウンロードします。
選択・メイン表示を変更agentContext.set読み取り専用のエージェントクライアント向けに、一時的なパスと表示状態を通知します。

直接のGUI操作がないAPI

session.addは、CLIが位置引数のパスを追加するときに使います。server.healthは互換サーバーの識別、server.shutdownは停止コマンドで使います。

Docsは組み込みコンテンツです。セッションエントリにはならず、List、Folders、HTML検索、インポート、エクスポート、削除、並べ替えの対象外です。

ワークスペース操作

Workspaceはsession.getのワークスペース情報を読み、workspaces.activateで選択します。New workspaceはworkspaces.createで作成後に選択します。Renameはworkspaces.rename、確認後の削除はworkspaces.deleteです。WebSocketで全タブの選択・ファイル群・順序を同期します。ブラウザーは表示中のIDを送信し、切り替え前の操作を拒否できるようにします。

お気に入り操作

行の星はsession.setFavoriteへ明示的な真偽値を送ります。aria-pressedで状態を示し、EnterとSpaceで操作できます。Favoritesはエントリをブラウザーで絞り込み、履歴にfileView=favoritesを保存します。更新はsession:updateで同期し、List全体の順序は維持します。Favoritesにはドラッグ用の操作部を表示せず、Clear Allを無効にします。

CLIのファイル指定は、トップURLに続けてタイトルとエントリのリンクを表示します。リンクはブラウザーのURLから対象を選ぶため、登録先のワークスペースを選択した状態で開いてください。追加応答は既存と新規の両方を解決し、List順を変更しません。

JSON-RPC

表の操作名はPOST /rpcへ送るメソッドです。ファイル配信とイベントは記載したHTTP・WS経路を維持します。引数・結果・エラーはAPIページで確認できます。ロゴの下に配布版、Docs内にオフラインのChangelogを表示します。
