GUIとAPIの対照表

ブラウザーUIは同じローカルサーバーのクライアントです。画面操作の背後で使うリクエストを示します。

GUIの動作サーバー操作UIへの反映
ビューアーを開くGET /api/session表示順のエントリ、サーバー識別子、選択機能の利用可否を読み込みます。
ファイルを選択GET /f/:id/プレビューiframeへHTMLを読み込みます。相対リソースにはGET /f/:id/*を使います。
Docsページを開くGET /docs/*セッションエントリを作らず、選択した言語とページを同一オリジンのiframeへ読み込みます。
セッション・ファイル変更を受信WS /wsファイルパネル、プレビュー、検索状態を更新します。
HTMLファイルを検索GET /api/searchソース内の固定文字列一致と打ち切り状態を表示します。
Select HTML filesPOST /api/session/pickネイティブファイル選択を開き、追加した最初のエントリを選択します。
Add folder…POST /api/session/pick-directory選択した直下・再帰範囲を使い、追加した最初のエントリを選択します。
ドラッグで並べ替えPATCH /api/session/order完全な表示順を永続化します。
ファイル行またはプレビューから1件削除DELETE /api/session/:idディスク上のファイルを削除せず、選択中のエントリをセッションから外します。
フォルダー行を削除DELETE /api/session/entries配下の全セッションエントリを原子的に削除します。
セッションを消去DELETE /api/session確認後、全セッションエントリを削除します。
Import session…PUT /api/session選択したモードに従い、全置換または未登録パスの追加を行います。
Export session…GET /api/session/exportセッションを変更せず、表示順またはパス順のJSONをダウンロードします。
選択・メイン表示を変更PUT /api/agent/context読み取り専用のエージェントクライアント向けに、一時的なパスと表示状態を通知します。

直接のGUI操作がないAPI

POST /api/session/addは、CLIが位置引数のパスを追加するときに使います。GET /api/healthは互換サーバーの識別、POST /api/shutdownは停止コマンドで使います。

Docsは組み込みコンテンツです。セッションエントリにはならず、List、Folders、HTML検索、インポート、エクスポート、削除、並べ替えの対象外です。
