2.0.0 — 未公開

この項目は公開済みリリースではありません。

  • Web UI、CLI、MCP内部通信を、POST /rpcのJSON-RPC 2.0と共通Commandsの21操作へ統一します。REST操作エンドポイントは廃止します。
  • 入力検証、ワークスペースとサーバー識別子の照合、エラー、更新通知をCommandsへ集約します。ファイル配信とWebSocket更新は維持します。
  • 公開済みのリリース履歴をオフライン閲覧用に同梱し、ファイルパネルへパッケージのバージョンを表示します。
  • メジャー更新を含む依存性更新を行い、Node.js 22以降への対応を維持します。

更新手順

  1. 更新前に起動中のサーバーを停止: zatto --stop
  2. 更新済みの場合は旧サーバーを停止: npx --yes @yuske-nakajima/zatto@1.2.0 --stop
  3. 公開版をインストールし、zattoを起動します。新CLIは旧サーバーを自動終了しません。
